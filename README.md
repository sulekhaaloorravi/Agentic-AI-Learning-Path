# 🤖 Agentic AI Learning Path — 90 Days × 30 Min/Day

> A practical, hands-on curriculum for early-career professionals entering the AI-native workplace.  
> **No advanced coding required.** Go from curious beginner to confident builder and team champion.

---

## 📋 Overview

| | |
|---|---|
| **Duration** | 90 days |
| **Daily commitment** | 30 minutes |
| **Total learning time** | ~45 hours |
| **Phases** | 3 (Foundations → Building → Leading) |
| **Weeks** | 12 |
| **Prerequisites** | Curiosity. No coding experience required. |

### Format key

| Badge | Meaning |
|---|---|
| 📺 Watch | Video content — lectures, demos, walkthroughs |
| 📖 Read | Articles, docs, guides |
| 🛠️ Practice | Guided exercises with existing tools |
| 🔨 Build | Create something from scratch |
| 💭 Reflect | Journaling, retrospectives, discussions |
| 🎓 Workshop | Present to others or collaborate |

---

## 🗺️ Learning Roadmap

```
Phase 1: Foundations     Phase 2: Building        Phase 3: Leading
Weeks 1–4                Weeks 5–8                Weeks 9–12
─────────────────        ─────────────────        ─────────────────
What is agentic AI?  →   No-code workflows    →   Measuring impact
How agents think     →   Prompt engineering   →   Advanced patterns
Tools & memory       →   Multi-agent systems  →   Teaching others
Ethics & safety      →   Agents in your job   →   Staying current
```

## 📚 Phase 1 — Foundations (Days 1–30)

> **Goal:** Understand what agentic AI actually is, how it differs from chatbots, and why it matters for your career. Build mental models before touching tools.

## 💡 Tips for Success

**Keep a learning journal.** Each Friday reflection is where the real learning happens. Don't skip it.

**Build something real.** The best way to learn agents is to automate a task you actually do. Toy examples are fine for learning mechanics; real tasks drive retention.

**Share early.** Don't wait until Week 11 to share your work. Show a teammate something every week, even if it's rough.

**Stay sceptical.** Agents fail in interesting ways. When something goes wrong, that's the most valuable learning moment.

**Community matters.** Find one other person doing this path. Weekly check-ins dramatically improve completion rates.
